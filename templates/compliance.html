Authorized service architecture

Commercial Railway Booking

This application is structured for use with an IRCTC-authorized PSP/RSP integration. It does not create an authorization by itself.

Customer security

  • No customer IRCTC password stored by this application.
  • No CAPTCHA collection or bypass.
  • No OTP collection or bypass.
  • No payment-card/UPI credentials stored.
  • No session-cookie sharing.

Commercial rules

  • Use only an authorized PSP/RSP account and integration.
  • Use only permitted service charges.
  • Do not advertise the app as IRCTC-authorized until authorization exists.
  • Do not use personal IRCTC IDs for commercial booking.
Before production: execute the required PSP/RSP agreement, obtain the provider's API documentation/credentials, complete security/privacy review, and configure the exact permitted charges and booking workflow from the agreement.
